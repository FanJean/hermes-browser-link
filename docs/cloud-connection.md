# 云端浏览器连接

云端功能让 ChatGPT 通过你自己的 Sites 插件操作已配对的本机浏览器。它使用独立 Native Messaging host，不替换 Hermes 的本地工具、身份或授权开关。支持 macOS 上已安装扩展的 Chrome/Edge。

## 配置站点

安装 1.8.3 后，本机云端 host 已注册；站点访问配置仍需初始化一次。先用 [站点源码](https://github.com/fanjing188/hermes-browser-link/tree/v1.8.3/cloud-link/site) 在 Sites 创建自己的私有站点，保留 D1 和 MCP 能力，发布后安装该站点创建的插件。源码里的托管配置不包含任何个人站点 ID；Sites 注册会写入你自己的 ID。

在本机运行以下命令，将网址换成自己的站点来源。命令隐藏询问 Sites 服务访问凭据，不要把凭据放到命令参数、Git 或 ChatGPT 消息里。

```sh
python3 "${HERMES_HOME:-$HOME/.hermes}/plugins/browser-link/cloud_link/client.py" \
  --home "${HERMES_HOME:-$HOME/.hermes}" configure --site https://your-site.chatgpt.site
```

服务凭据用于通过私有站点门禁；设备还必须完成独立配对。保存站点配置不会授权浏览器。已经配置过本站点的安装保留原配置；命令不会覆盖它。

## 配对

1. 保持浏览器打开，在扩展弹窗点“云端连接”。
2. 复制十二位连接码，点“打开配对网页”。连接码五分钟有效。
3. 网页输入连接码，核对浏览器并确认配对。网页显示实际在线状态、浏览器类型和云端权限。
4. 在 ChatGPT 连接该站点的插件，再开始浏览器任务。

Chrome 和 Edge 分别配对。弹窗可以管理连接、重新配对或断开。网页上的断开只停止该浏览器的云端访问，不改变原本地调用。

## 授权范围

默认使用智能审批：首次读取某个网站要在本机确认，写入继续逐项确认。“云端完全访问”只能从本机弹窗开启，允许所有 HTTP/HTTPS 网站的云端任务页操作，免逐项确认；已有个人标签页不授权。网页和云端工具不能开启这个开关。

云端和本地开关独立。切换云端权限会结束现有云端任务并保留页面，新任务使用新的模式。云端接口不提供本机文件上传、Cookie 镜像、任意 JavaScript、原始 CDP 或本机凭据通道。

## 多个对话和多个页面

每个 ChatGPT 对话分别调用 `cloud_browser_create`，创建标记使用全新 UUID。保留返回的 `session_id`，同一对话后续调用沿用它，不要复制其他对话的任务身份。每个动作使用唯一 `request_id`，相同会话内同标记改参会被拒绝。

创建或操作返回 `command_id`。用 `cloud_browser_result` 查询结果：queued/claimed 表示仍在处理；完成正文只交付一次，取走后清除。已取走或未知的结果不能靠重发动作恢复，先用 get/list 核对本机任务或页面状态。

同一任务可以打开多个工作页，并发提交不同 `tab_id` 的操作。同页面按提交顺序执行；建页、恢复和关闭等待前面的页面动作结束。浏览器焦点输入继续使用既有工作窗口锁，不把两个页面的键盘输入混在一起。

本机有六个页面执行线程，为查询和取消保留两个线程。通信交换合并心跳、回执与最多八条命令领取，任务等待审批不会阻断其他任务。空闲时轮询逐步降至三秒。

云端以最近三十秒内的心跳判定连接有效，容纳一次网络超时后的重连等待；本机明确报告浏览器断开或配对撤销时立即拒绝新动作。云端 Native 端口断开后约 1.5 秒尝试重连，连续失败逐步延长等待，最长三十秒。重连不重放原动作。

任务隔离不等于网站账号隔离。登录态、购物车、退出登录等账号状态仍共享；涉及同一账号状态的任务需要自行协调。

## 结束和回收

完成时调用 `cloud_browser_close`，核对 `state` 与 `cleanupState`。关闭入队后不再接受该会话的新页面动作。需要交还页面时传 `keep_tabs=true`；默认只清理由该任务创建且能证明归属的页面。

取消等待用 `cloud_browser_cancel`，之后可显式 resume，建立新代次授权；旧动作不会自动重放。清理尚未确认时，用 close 的 `cleanup_action=status` 读取清理证明；只有原本机证明允许时才使用 `cleanup_action=retry`。

断线和权限切换停止领取并回收云端任务的线程、连接和身份。重连先核实上次会话收尾；在途创建完成后再扫描一次，避免遗漏晚创建的任务。一小时没有本机调用且没有在途动作的云端会话会撤权并关闭自己创建的工作页；仍等待人工处理的页面交还用户。确认清理后关闭路由。未知归属的页面保留，不伪报已清理。

## 数据保存

执行日志继续由原 daemon 写入 `$HERMES_HOME/plugin-data/browser-link-native/task-logs/`。云端不提供执行历史。

网页右上角“最近步骤”显示操作结果和固定错误码，新写入的失败或未知结果记录用 `errorCode` 保留具体原因，工具读取日志时也保留该字段。“结果不确定”表示操作可能已经发生，应先核对页面实际状态，不能直接重复提交。`content_shield_uninspectable` 表示内容保护无法检查页面中的框架或封闭组件，本次操作被拒绝；它与连接错误分别说明。

云端保存配对、路由和去重摘要。请求被领取后清除输入与动作名；回执正文取走即清除，未取走回执两分钟后失效，在后续通信中清除。平台的基础 HTTP 访问记录不属于应用执行日志；应用不向这些记录输出网页正文或输入。

本机云端配置位于 `$HERMES_HOME/plugin-data/browser-link-cloud/`，按浏览器实例隔离，凭据文件权限为 0600。不要提交该目录。

## 验证范围

1.8.2 的发布检查包含云端授权、Native 帧、调度、关闭屏障、去重、回执清除和站点 HTTP/MCP 回归。Chrome 与 Edge 已通过实际云端示例页填写和清理回执核实。Chrome 的多会话、三页并发及审批期间其他会话继续执行沿用此前独立验收记录；本次两浏览器填写验收不代表 Edge 的完整并发矩阵。

一小时回收使用可控时间测试，未等待一小时墙钟时间。当前浏览器调用接口也不保证已通过所有第三方网站的业务验收。
