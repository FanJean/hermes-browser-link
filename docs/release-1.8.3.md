# Hermes Browser Link 1.8.3

1.8.3 为 macOS 正式稳定版，统一页面元素解析与操作能力描述，并修复动态框架造成的只读快照中断。

## 标准控件描述与执行

- 交互元素返回固定 `actions`：点击、按键、填写、勾选、选择，对应现有 `ref_*` API。解析库与执行器共用角色、禁用、只读及编辑资格判断。
- 角色采用首个有效非抽象 WAI-ARIA token；未知角色不覆盖原生控件语义。菜单复选/单选使用统一勾选动作，ARIA 禁用祖先约束后代，原生 fieldset 保留首个 legend 例外。
- 原生三态复选框按 mixed 核验，不能把底层 boolean 当作已达到目标；一次点击不能达到目标时，在派发前拒绝，不自动点击两次。
- ARIA 只读编辑区及非文本输入不声明填写能力。动作清单不等于授权或可点击保证，执行前继续检查引用、权限、敏感字段和遮挡，执行后核验状态。
- Python helper 利用动作清单排除同名展示控件；官方紧凑快照也显示可用动作。公共结果只投影固定动作词表，不接收页面值或伪造对象。

## 动态读取与实现升级

- 新结构读取遇到前后文档标识变化时丢弃旧结果，最多重新读取一次，并重新执行全部保护检查；持续变化仍拒绝输出。
- 保护设置变化、点击/填写、脚本、截图、单次审批凭证及 frameToken/cursor/baselineId 读取不自动重试。缓存回放不重新执行动作。
- 读取失败提示重新读取，写入失败继续提示核对实际结果。升级语义实现后撤销旧引用，重新创建当前实例。
- 冷安装声明增加约 2.5KB；固定八次热调用约 2.6KB，仍受 6KB 原上限约束。

## 安装

下载 `hermes-browser-link-1.8.3.zip`，解压后运行 `./install.sh`；已有安装运行 `./install.sh --upgrade`。更新后重载 Chrome/Edge 扩展并重新加载或重启 Hermes 插件运行时。安装包无需 Node.js。

个人环境更新需等待活动浏览器任务结束，不能用关闭其他任务的方式绕过更新保护。云端站点源码版本同步为 1.8.3；本机升级与 GitHub Release 不替代站点所有者的托管发布。

## 验证范围

发布要求核心离线测试、固定 Hermes 集成门禁、版本闭包、源码隐私扫描、安装包 SHA256 和隔离升级检查通过。临时 Chrome/Edge 完整链路验证菜单勾选、三态边界、只读拒绝、动作清单公共投影及现有复杂控件流程。

浏览器验收使用临时 profile 和本地合成页面，不代表第三方网站业务提交验收。其他操作系统不在本次安装支持范围。
