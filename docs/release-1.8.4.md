# Hermes Browser Link 1.8.4

1.8.4 为 macOS 正式稳定版，修复本地桥接退出崩溃、历史清理响应超限导致的重连循环，以及悬停按钮造成的会话引用失效。

## 本地桥接退出与历史清理

- Native host 的标准管道改为可取消的无缓冲读写；断连时唤醒 socket 并等待两个转发线程结束，避免 Python 在关闭标准输入时因缓冲锁争用触发强制中止。
- 半截消息、输出堵塞和断管均进入同一退出路径，保留消息大小校验和部分写入处理。
- 重连清理只传输任务身份、实例、代次、状态和标签证据，避免大量历史操作详情超过 1 MiB 单帧上限。完整历史账本与普通任务读取的详情继续保存。

## 会话引用与读取

- 推断点击行的名称不再混入置顶、改名、删除等独立子控件的文字；悬停显隐不改变原业务目标，独立控件仍可单独定位。
- 业务标题变化、身份不匹配和作用域改变继续拒绝旧引用；正文和表格各列的链接文字保留。
- 更新语义实现代次，升级后撤销旧实现的引用并重建。引用身份、权限、敏感字段、遮挡和效果回读检查继续执行。
- 任意 JS 遇到不可检查框架时仍可被内容保护拒绝；本次修复不关闭保护。读取已有内容优先使用受支持的结构化入口。

## 安装

下载 `hermes-browser-link-1.8.4.zip`，解压后运行 `./install.sh`；已有安装运行 `./install.sh --upgrade`。更新后重载 Chrome/Edge 扩展并重新加载或重启 Hermes 插件运行时。安装包无需 Node.js。

更新个人环境前等待正在执行的浏览器任务结束。断连或重启后需要重新确认的任务不会自动重放。云端站点源码元数据版本同步为 1.8.4；GitHub Release 不替代云端站点所有者的托管发布。

## 验证范围

发布前验证核心离线测试、固定 Hermes 集成门禁、版本闭包、源码隐私与密钥扫描、安装包 SHA256，以及隔离安装/升级和临时浏览器中的变更流程。

退出回归使用真实管道和隔离 UDS，覆盖半截帧、输出堵塞及 500 条历史经过真实 host/daemon 后继续读取。悬停回归覆盖独立控件、正文、多列表格、标题变化拒绝及实现更新。个人环境另已执行安装版 Hermes SDK 前置鉴权、Python helper、Native bridge 与 Chrome 的原会话点击和结构化读取，回执确认送达、观察到效果、完整读回已有内容并清理验收任务。

真实浏览器证据与离线模拟分开记录。个人站点的单次读取不代表所有第三方网站、业务写入或其他操作系统的验收；安装支持范围仍为 macOS。
