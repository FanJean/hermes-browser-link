# Hermes Browser Link 1.8.2

1.8.2 为 macOS 正式稳定版，修复已解析控件被无关 iframe 阻断的问题，并改善工作窗口回收、解析反馈和执行日志。

## 原生控件操作

- 顶层原生引用动作使用宿主通过实际 DOM 节点建立的保护范围，无关可见跨源 iframe 不再阻断原生输入框、按钮、复选框及 select。
- 框架包含或覆盖目标时继续拒绝；高亮等待或滚动期间框架移入目标也会在派发前拒绝。嵌套框架使用最外层宿主坐标。
- 操作后及结果交付继续核验目标与保护设置，可访问内容仍脱敏。模型不能传入节点编号授权，结果回放不重复写入。
- 截图、脚本、坐标/选择器动作、ARIA 复合控件及显式子框架入口保留原有严格检查。

## 工作窗口与解析反馈

- 保存的窗口或标签编号失效后查找已有扩展首页，复用工作窗口。
- 最后任务清理成功且窗口只剩扩展首页时关闭空窗口。有其他任务、保留结果或用户页面时继续保留。
- 解析时显示绿色扫描光带，语义识别后短暂绘制真实可见元素边框。暂停、错误及新步骤清理旧效果，截图不包含装饰，减少动态效果模式使用静态反馈。

## 执行日志

失败或未知结果用固定 `errorCode` 保留原因，工具和最近步骤统一交付中文说明。已派发后的控件核验失败仍保留结果不确定标记，不再用“未派发”文案误导重试。历史缺失字段不会补造。

## 安装

下载 `hermes-browser-link-1.8.2.zip`，解压后运行 `./install.sh`；已有安装按安装说明升级。更新后重新加载 Chrome/Edge 扩展并重新启动 Hermes。安装包不需要 Node.js。

独立云端站点保留原配对、登录与数据库配置；托管的 MCP 版本同步为 1.8.2。本机安装包不能代替站点所有者发布自己的云端站点。

## 验证范围

发布使用核心离线回归、固定 Hermes 集成门禁、源码隐私扫描、版本闭包及隔离安装包检查。临时 Chrome/Edge 已验证原生填写、选择、复选框、按钮、目标覆盖和等待期间移入的拒绝、严格截图/复杂控件、结果回放及清理；已安装两浏览器的实际云端示例页填写与清理也已核实。

上述输入只使用本地合成页面，不代表第三方网站的注册、支付或表单提交验收。其他操作系统不在本次安装支持范围。
