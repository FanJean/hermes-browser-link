# Hermes Browser Link 1.8.1

1.8.1 为 macOS 正式稳定版，包含页面元素解析、任务结束清理、云端连接恢复和版本一致性修复。支持已安装扩展的 Chrome 与 Edge。

## 元素解析

- 控件本身未变化时，周边进度文字更新不再让旧引用误报歧义。
- 引用重定位限制在原快照指定区域；区域替换、虚拟记录索引变化、跨文档或候选歧义时仍拒绝旧引用。
- 语义快照和结构化表单统一识别空 contenteditable、true 和 plaintext-only 编辑区；填写与回读使用相同判断。

## 任务结束和云端连接

- Hermes 成功完成默认立即关闭任务自建工作页。人工等待、暂停、明确交还用户的页面和用户自己的页面继续保留。
- 云端没有对话结束事件。MCP 指令要求调用方回复用户前关闭任务并核实回执；无在途操作的闲置回收关闭自建页，断线仍交还页面。
- 修复云端 Native 端口重连等待和心跳在线边界；未知动作不自动重放。

## 版本一致性

仓库、插件、桌面元数据、Chrome/Edge 扩展握手及云端 MCP 包统一为 1.8.1。打包和运行检查会拒绝版本错配。本机开发同步覆盖已安装的命名 profile 副本及指向根插件的链接。

## 安装

下载本 Release 的 `hermes-browser-link-1.8.1.zip`，解压后运行 `./install.sh`；已有安装运行 `./install.sh --upgrade`。更新后重载 Chrome/Edge 扩展，重启 Hermes。安装包不需要 Node.js。

云端 Sites 站点需同步更新自己的站点源码；本机升级不会自动替其他用户发布站点。参见 [云端连接](cloud-connection.md)。

## 验收与限制

本次行为修改已通过固定 Hermes 离线门禁、临时 Chrome/Edge profile 的复杂控件与立即关闭链路，以及已安装两浏览器的实际站点只读解析和关闭回执核实。发布前重新核对版本闭包、安装包和 CI。

实际站点检查没有填写或发送消息，不是站点业务提交验收。一小时闲置回收使用离线检查，没有等待一小时墙钟时间。浏览器登录态和网站账号状态仍共享；其他操作系统尚未纳入安装支持范围。
