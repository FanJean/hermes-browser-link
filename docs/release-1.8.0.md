# Hermes Browser Link 1.8.0

1.8.0 为 macOS 正式稳定版，支持已安装扩展的 Chrome/Edge。安装包不需要 Node.js；源码和站点维护仍使用锁定开发依赖。

## 云端连接

- 扩展弹窗生成五分钟有效的连接码，网页核对并配对；浏览器在线状态以实际本地连接与心跳为准。
- 本地与云端授权独立。“云端完全访问”只从本机开启，仅授权云端任务页，已有个人标签页不授权。
- 不同 ChatGPT 对话分别创建任务；同一任务多个页面可以并发，同页面保持顺序，关闭等待已有动作收尾，取消和状态查询有保留执行容量。
- 合并心跳、命令领取和回执交付；审批等待不阻断其他会话。完善断线、闲置和晚创建任务回收。
- 执行日志仍在本机。云端输入领取后清除，回执取走即清除；仅保留配对、路由与防重复摘要。

## 本地读取与屏蔽修复

- 补齐语义上下文、控件状态、slot 标签和虚拟表格索引；结果投影不放行输入值或原始属性。
- 支持同源 iframe 内的 closed Shadow DOM，并补齐有界、显式范围的无障碍控件补充。
- 不可读取的子框架不阻断父页面读取；截图保护与内容屏蔽使用同一覆盖边界，无法确认时拒绝输出。
- 修复 CSS 伪元素命中检查、跨层隐私字段及空任务清理状态。

## 安装与更新

从本 Release 下载 `hermes-browser-link-1.8.0.zip`，解压后运行 `./install.sh`；已有安装运行 `./install.sh --upgrade`，重载浏览器扩展并重启 Hermes。

旧安装先手动升级一次，安装当前公开仓库的自动更新源。1.8.0 属于正式更新通道，后续稳定版仍经 SHA256、ZIP 路径、完整包清单和扩展身份校验，并在浏览器与 Hermes 退出后安装。

云端调用需要自己的 Sites 站点、服务访问配置和插件连接；安装本机包不会自动建立站点或配对。参见 [云端连接](cloud-connection.md)。

## 验收和限制

发布要求核心回归、完整固定 Hermes 门禁、安装包闭包与公开源码扫描通过。运行结果、源码提交及附件校验值另记在发布验收记录中；测试通过不等于所有网站业务都已验收。

Chrome 已实测多个独立云端会话、三页并发、审批等待、取消后恢复和最终关闭；Edge 已配对在线，当前云端并发页面验收在 Chrome 完成。闲置一小时回收使用可控时间测试。

浏览器登录态和网站账号状态仍共享。Python 工作流以本机用户权限执行，不是系统沙箱。其他操作系统仍未纳入安装支持范围。
