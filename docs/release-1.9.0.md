# Hermes Browser Link 1.9.0

macOS 版本，适用于已登录的 Chrome / Edge。日期：2026-10-09。

## 改动

- 移除智能审批开关、模式切换和普通任务重复确认。在扩展明确确认连接后，本地任务页读取、导航、点击、填写、JS/CDP 和 Python 工作流直接执行；云端仍只提供受控读取、点击和填写，不新增任意脚本接口。
- 保留接管、继续、停止和凭据保护。Cookie 镜像、接入已有 OAuth 登录小窗仍须独立确认；连接授权不会自动开放个人标签页。
- 离线或未知状态不算已授权。云端断连先撤销本机权限；畸形命令整批拒绝，不提前消费回执或派发其中一条。
- 已派发的登录小窗接管遇到异常时，宿主和扩展一致撤权。结果未知不能重放；批准后的脚本只读查询实际授权，再操作当前获准的页面。
- 连接码复制状态绑定实际复制的码。扩展说明、安装包说明、功能清单和接口参考与当前连接流程保持一致。
- Native host 先启动两条转发线程再发送连接握手；提前到达的浏览器消息不会抢在认证之前。启动延迟、半截帧和断连退出均纳入固定回归。
- 一份共享主程序，命名 profile 用受控直接链接引用；迁移旧全副本和未登记入口时保留停用状态、各自权限与私有数据。升级备份及 Hermes Desktop 的应用级界面缓存继续保留。
- 升级失败按原目录或原链接类型回滚；未知链接、数据或祖先链接、建链失败及活动/未知任务状态拒绝，不提权、不回退复制，也不自动结束活动任务。

- 桥接在完全安全空闲后等待 30 秒自行退出，后台 Cookie 镜像清理完成前不退出。升级及开发同步共用生命周期与云端门禁，不强停；旧云入口通过显式 `--upgrade --maintenance` 一次性迁移，旧自动更新器拒绝绕过新门禁。

## 安装

下载本版本的 `hermes-browser-link-1.9.0.zip`，不要下载 GitHub 自动生成的 Source code ZIP。解压后运行 `./install.sh`；已有安装运行 `./install.sh --upgrade`。安装包无需 Node.js，需要 Python 3.11+ 和 Hermes；源码安装另需 Node.js 22.12+。Hermes 验证版本为 0.21.4。

加载安装器打印的扩展目录，在扩展中确认连接授权；更新后分别重载 Chrome / Edge 扩展，并重启使用该插件的 Hermes 会话。安装完成不等于浏览器已连接，文件更新不等于旧会话已生效。

## 发布验收与边界

发布以同一源码提交的 `npm test`、`npm run verify`、公开源及密钥扫描通过，且独立复审无阻断为门槛。浏览器验收使用隔离 Chrome / Edge、本地合成登录页和临时安装，覆盖直接执行、接管、停止、密码/验证码保护及原登录小窗保留；UI 同时检查 1440 / 375 视口。

本版本支持范围为 macOS + Chrome / Edge；Windows、Linux 未完成安装验收。合成登录页验收不代表真实 Google 账号已登录。点击“放开页面”只移除本地遮罩，不证明后台任务已经停止。

原始 CDP 的持久脚本可能在后续页面继续运行，包括其他网站；它不是只读沙箱。插件在任务结束或撤权时清理登记脚本，但不能保证导航时已登记的脚本尚未执行。
