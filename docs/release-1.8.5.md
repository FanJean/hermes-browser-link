# Hermes Browser Link 1.8.5

1.8.5 为 macOS 正式稳定版，修复任务结束后工作页被过度保留，并提升页面元素点击、填写和选择的稳定性。

## 任务结束与工作页

- `browser_shared_close(keep_tabs=true)` 必须同时传 `handoff_reason`（captcha、login、verification、final_submit、user_requested），缺失或不合法时拒绝，任务保持原状态。
- 工具说明改为：只有本轮明确请用户立即在该页完成一步时才保留页面；遇阻、结果未知、读不到或被遮挡时记录 URL 和停点后普通关闭。
- 交接原因写入任务记录并在清理回执中返回。清理状态区分日志恢复异常（`workspace_unknown`）与缺少创建记录（`no_journal`），不扩大标签页清理权限。

## 页面交互

- 点击和填写前自动滚动到可视区，并在有上限的时间内等待元素可见、启用、位置稳定且命中测试通过；仍被遮挡时不派发，返回遮挡元素的角色和名称。
- 点击触发整页导航或 SPA 路由变化时，依据本次派发后的导航事件判为成功并返回导航类型；动作已确认后，内容保护复查失败只拒绝页面输出，不把动作标为结果未知。
- 失败和未知结果始终带固定错误码、可重试标记和下一步提示；部分送达的动作记为结果未知，不会自动重复派发。
- 下拉选择按规范化标签匹配；自定义下拉无法预检时提前返回 `custom_select_unsupported` 并提示逐项点击。
- 只有图标的按钮和单控件包装可使用 title 或邻近文字作为名称。

结果未知的写操作仍不自动重放；内容保护、敏感值屏蔽和不可读框架的拒绝规则不变。

## 安装

下载 `hermes-browser-link-1.8.5.zip`，解压后运行 `./install.sh`；已有安装运行 `./install.sh --upgrade`。更新后重载 Chrome/Edge 扩展，并重新加载或重启 Hermes 插件运行时。安装包无需 Node.js。

## 验证范围

核心离线测试和版本闭包检查通过。临时 Chrome profile 中，十类本地固定页面场景（列表重渲染、cookie 横幅遮挡、动画按钮、延迟启用、SPA 跳转、整页导航、原生与自定义下拉、无关不可读 iframe、图标按钮）各运行 10 次，全部通过；关闭与交接的三项流程通过。本地固定页面结果不代表所有第三方网站；安装支持范围仍为 macOS。
