# 云端浏览器连接

云端连接采用独立 Native Messaging host，不替换原本地 host，不重启原本地 daemon。浏览器打开扩展后，本机云端进程随独立 Native 端口运行。

## 配对

1. 在 Chrome 或 Edge 扩展弹窗点击“云端连接”。
2. 复制十二位连接码，点击“打开配对网页”。
3. 网页端输入连接码，查找并确认浏览器。连接码五分钟有效。
4. 网页显示浏览器实际在线状态、访问范围和本机权限状态。

已配对浏览器可从弹窗管理、断开或重新配对。浏览器关闭或本地桥断开后，网页不会仅凭后台进程心跳显示浏览器在线。

## 独立授权

“云端完全访问”只由本机扩展开启。开启后允许所有 HTTP/HTTPS 网站的云端任务页读写并免逐项确认；关闭后使用按网站与操作确认。已有个人标签页不授权。本机文件、Cookie 镜像和原始脚本通道不在该云端接口内。

云端开关和原本地权限独立；权限切换会结束当前云端任务并保留页面。每次云端动作前重新验证任务所属浏览器和本机授权，网页与 MCP 工具无法开启完全访问。

## 数据位置

原 daemon 继续在原本地位置保存执行日志。云端数据库只保存配对、会话路由、通信信封和防重复调用摘要，不提供执行历史。

请求被领取后，云端清除动作名和输入。回执正文只作短暂通信中转，取走即清除；未取走回执两分钟后失效，在后续通信中清除。去重与交付摘要不含页面正文。平台自身的基础 HTTP 访问日志不属于应用执行日志，本应用不向这些日志输出网页内容或输入。

本机配置位于 `~/.hermes/plugin-data/browser-link-cloud/`，文件权限 0600，实例按目录隔离。既有配对的身份和去重记录会迁入对应实例，原本地调用身份不迁移。

## 安装和验证

标准安装包已包含云端 Native host 注册。已有源码安装可运行 `python3 cloud-link/install-host.py` 注册独立入口，再重载扩展。首次服务访问配置由站点所有者初始化，普通配对流程不需要终端或输入访问凭据。

```sh
python3 -m unittest discover -s cloud-link/tests -v
node --test tests/native-extension/cloud-link.test.mjs
cd cloud-link/site
npm test
npm run build
npm run validate
```

云端接口仍为 `cloud_browser_devices/create/get/list/run/result/resume/cancel/close`。完成正文只交付一次；`result_delivered=true` 且 `result=null` 表示已经取走，不能重发动作，可用 get/list 核对本机任务。未知结果同样不能重发。

## 多会话、多页面与回收

每个 ChatGPT 对话分别调用 create，使用全新 UUID 作为创建 request_id。返回的 session_id 是此对话的路由凭据，不能复制给其他对话。每个会话由本机派生独立 owner；同名操作标记在不同会话分别去重。同一任务的不同 tab_id 可并发调用 run，每个操作分别用 command_id 取回结果。

本机最多同时执行六个页面操作，并为查询和取消预留两个线程。页面操作按同页提交顺序执行；建页、恢复和关闭是任务屏障，等待前面的页面操作完成。取消可越过等待，状态查询不会被审批挡住。并发页面仍共享同一浏览器登录态；同一账号的购物车、登录切换等网站状态也共享，需要调用方避免互相冲突。

通信交换一次完成心跳、回执补交和最多八条命令领取。浏览器动作由独立执行线程处理。空闲轮询逐步降低到三秒，心跳状态最多每五秒写入；每会话最多八条未完成请求，设备正常队列二十条，为取消和关闭保留四条容量。

正常结束调用 close，查看 state 和 cleanupState；关闭入队后拒绝新增页面动作。清理尚未确认时，使用原 close 的 cleanup_action=status 核实，仅在获得原本机清理证明后可 cleanup_action=retry。需要保留页面时传 keep_tabs=true。cancel 撤权并允许之后显式 resume；不自动重放被取消动作。

一小时无本机调用且没有在途操作的云端会话会撤权并交还页面，清理确认后同步关闭路由。正常断线和权限切换会停止领取、结束等待并回收云端套接字和线程；在途创建收尾后再扫描一次，防止留下孤儿任务。进程异常退出后，已领取命令只补交未知回执，不能重放；原 daemon 的持久化租约和空闲回收继续生效。

会话关闭后保留最小路由与请求摘要，防止旧请求重放；不保存云端执行历史。已确认结束的本机云端身份会从云端私有身份索引释放，身份密钥和原本地身份索引不变。
